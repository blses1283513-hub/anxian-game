# 音檔替換

遊戲的配樂和音效預設由程式即時合成。把音檔放進這個資料夾（`public/audio/`），檔名照下表，遊戲就會自動改用你的音檔，不用改程式。

- 支援 `.mp3`、`.ogg`、`.m4a`、`.wav`。
- 配樂會循環播放，建議 30–90 秒、頭尾能接上的片段，檔案盡量小（手機要下載）。
- 音效只播一次。
- 放上去之後重新整理網頁即可；沒放的項目繼續用合成音。
- 請只放你有權使用的音檔。這個 repo 是公開的，放進來的檔案任何人都能下載。

| `music_day` | 感染戰：每日進行中 |
| `music_urgent` | 感染戰：每日最後一分鐘 |
| `music_win_citizen` | 市民獲勝、警察獲勝 |
| `music_win_cure` | 解毒劑製成獲勝 |
| `music_win_terror` | 恐怖分子獲勝、小偷獲勝 |
| `music_none` | 無人獲勝 |
| `music_chase_thief` | 地鐵追捕：小偷行動 |
| `music_chase_cop` | 地鐵追捕：警察行動 |
